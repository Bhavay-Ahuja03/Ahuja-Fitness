# 🏋️ Ahuja Fitness

A modern and responsive gym website built using **HTML5 and CSS3**.

This project was created to practice and demonstrate frontend development concepts such as responsive layouts, Flexbox, CSS Grid, hover effects, background images, transitions, and modern UI styling.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile
- Modern navigation bar
- Hero section with call-to-action
- Gym programs section
- Why Choose Ahuja Fitness section
- Membership plans
- Interactive hover effects
- CSS transitions and animations
- Responsive pricing cards
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Media Queries
- CSS Transitions & Hover Effects
